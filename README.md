# 深流潜航 Abyssal Voyager

复古像素潜艇游戏。Vite + TypeScript + Canvas 2D，全程 2D 绘制，不用 Three.js、3D 引擎或多边形网格。
潜艇用切片叠层（sprite stacking）做出立体感，在海带林、珊瑚礁和岩壁峡谷之间潜航。

**在线试玩：https://pengyuchen2025-ship-it.github.io/Abyssal-Voyager/**（电脑和手机都能玩）

## 操作

打开网页是开始界面：潜艇舱室，透过大圆窗看到海底和自己的潜艇。点「开始潜航」（或回车 / 空格），镜头推进圆窗进入游戏；点「操作指导」（或 H），镜头推向左边第一台电脑：电脑屏幕和圆窗一样是挖空的，后面是一块单独的显示屏界面（平时是滚动的声呐波形待机画面，推近后屏幕「开机」，复古终端风格逐行打出操作说明），Esc / 点一下返回。进入游戏后左侧显示操作说明 10 秒；之后按 Esc（触屏：右上角「暂停」）暂停并显示操作说明。手机需要横屏，竖着拿会提示横过来。进入新海域时画面上方淡入地名。

| 操作 | 鼠标 / 键盘 | 触屏 |
|---|---|---|
| 转向、升降 | 鼠标在潜艇（潜望镜里是十字线）左右转向、上下升降；也可以用 A / D、W / S、方向键、滚轮 | 按住屏幕拖动；右下角「上浮」「下潜」 |
| 加速 | 按住鼠标左键或 Shift（1.7 倍） | 右下角「加速」 |
| 氮气加速 | F、E 或鼠标右键：冲刺约 2.4 秒（2.8 倍），能量条约 9 秒回满，剩 1/4 以上才能用 | 右下角「氮气」 |
| 翻滚 | 单击，或 R | 轻点屏幕 |
| 切换视角 | 空格升起潜望镜、切到「潜望镜」视角，再按一次退回「尾随」并收起潜望镜；也可以 1 / 2 直接选；右上角按钮 | 右上角按钮 |
| 暂停 / 操作说明 | Esc（切到别的标签页也会自动暂停） | 右上角「暂停」 |

## 开发

```bash
npm install
npm run dev       # 本地开发
npm run build     # 类型检查 + 打包；生成单文件版 dist/single.html，并复制到 docs/index.html
```

`docs/index.html` 是整个游戏的单文件版本（JS 内联，约 60 KB），GitHub Pages 从 `docs/` 目录发布。改完代码跑一次 `npm run build`，把 `docs/` 一起提交即可更新在线版。

调试参数：`?play` 跳过开始界面直接进游戏，`?nohint` 不显示开局的操作说明，`?view=periscope` 直接进潜望镜（旧的 `?view=cockpit` 也认），`?seed=数字` 换一张地图，`?touch` 强制显示触屏按钮，`?noauto` 关掉自动降分辨率。

## 模块

| 文件 | 内容 |
|---|---|
| `renderer.ts` | Uint32Array 帧缓冲区（短边约 230 像素），putImageData 输出，CSS 整数倍放大 + pixelated；后期暗角和 4×4 有序抖动；潜望镜里整幅画面随横滚旋转 |
| `sub.ts` | 潜艇：16 张 32×32 调色板索引切片。按水平层绘制，层内逆向映射（航向 → 俯仰 → 横滚）+ 最近邻采样，1 像素深色描边；指挥塔上可升降的卡通潜望镜：灰色伸缩管 + 橙色镜管，顶上弯成 J 形接一段带圆形镜片的镜筒（球串取样、按深度排序绘制）；升起时镜片先对着尾随镜头，快到顶时转向前方 |
| `world.ts` `terrain.ts` | 4 层可平铺 value noise → 512×512 循环高度图，按高度分位数分 8 带上色；每列从近到远绘制，用占用掩码保护已写像素；取样点对齐世界网格防闪烁；焦散光 |
| `objects.ts` `water.ts` `particles.ts` `trails.ts` | 立起来的海带和珊瑚（切片叠层）、固定深度的水母群（独立循环噪声图）和鱼群、头顶水面、光柱、浮游光点、螺旋桨气泡流、翼尖水流线、潜艇影子 |
| `main.ts` | 主循环、HUD、开始界面状态（开始界面 → 推进圆窗 → 游戏）、操作指导的镜头推近、暂停（Esc）、开局操作说明、海域地名。开始界面上把游戏镜头挪到圆窗中间并缩小；推进圆窗时背景画布（CSS 缩放）和游戏镜头绕同一个不动点按同一倍数放大，后半段背景淡出，到底正好是正常尾随镜头 |
| `menu.ts` `assets/menu-bg.webp` | 开始界面背景：AI 生成的潜艇舱室像素画（去掉了图上的标题和按钮、圆窗挖空），运行时缩到和游戏画面完全一样的像素网格，再做同样的有序抖动量化；圆窗和左边电脑屏幕都挖空；记录它们在原图上的位置，屏幕上补一层玻璃反光和暗边。显示屏界面是 900×600 的 HTML，用仿射变换贴到倾斜的屏幕上 |
| `camera.ts` `game.ts` `input.ts` | 一套投影实现尾随和潜望镜两种视角，切换时逐项插值俯仰角、透视强度、缩放、朝向、支点位置；进潜望镜时先升起镜管（约 0.75 秒）、镜头转向前方，再把镜头送到镜管顶端，退出时镜头先回来再收镜管；远景雾；氮气加速 |
| `index.html` | HUD、开局操作说明、暂停卡片、海域地名（HTML + CSS）：HUD 用像素风边框（SVG 九宫格，四角缺一格、左上亮右下暗）；地名不加框，直接在画面上方淡入淡出 |
| `periscope.ts` | 潜望镜目镜：圆形视野（进入时像光圈一样从屏幕外收拢）、边缘暗角、带测距刻度的十字分划线、顶部真方位刻度带；外面黑色镜筒壳体上有声呐（扫描线扫出比潜艇高的岩壁）、方位 / 深度 / 航速读数和氮气格，贴近海床时金属环闪红 |

青绿 / 紫雾两种氛围按区域混合：地图上有一张低频「区域图」，游进紫雾区后海床、海带、水母和整片水色都会慢慢变过去。
